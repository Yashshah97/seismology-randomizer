# Usage

```python
import seismology_randomizer
```

Each module is self-contained; see docstrings for the API:

- `seismology_randomizer.main` — Main entry point for the project
- `seismology_randomizer.engine` — Monte Carlo experiment runner with confidence intervals
- `seismology_randomizer.data_loader` — Loads and preprocesses earthquake waveform data
- `seismology_randomizer.results_processor` — Processes results from Monte Carlo experiments, including generating plots and statistics
- `seismology_randomizer.tests_test_engine` — Unit tests for the engine module
- `seismology_randomizer.docs_conf` — Configuration file for Sphinx documentation generation
